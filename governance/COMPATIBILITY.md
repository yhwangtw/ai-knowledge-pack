# 相容性與導入證據

| 讀取方式 | 本版狀態 | 限制 |
| --- | --- | --- |
| GitHub main checkout | 公開 HTTPS clone 已驗證 | 公司依核准流程拉取 main，記錄 commit，後續離線閱讀；不要求 agent 自行連線 |
| 一般 UTF-8 文字編輯器 | 已做位元組與編碼檢查 | Markdown 可作純文字閱讀，無需外部字型或網站 |
| 顯式讀取本機檔案的 coding agent | 文件設計支援，尚未產品實測 | agent 與模型必須已核准且能離線運作 |
| 手動依順序貼入文字 | 文件設計支援 | 使用者需保持完整上下文並確認推論不出企業邊界 |
| 以 SKILL.md 自動探索 | 未實測 | 各產品版本、搜尋路徑與依賴讀取不同，不保證自動安裝 |
| Nexus 納管 checkout 文件 | 未在公司實測 | 管理員確認清單內文件的格式、權限、容量、清理與版本政策；取得入口仍為 GitHub main |
| Harbor 作為工件儲存 | 未封裝、未實測 | checkout 中的純文字文件不是容器映像；另行 OCI 封裝需公司核准，本包不提供程式 |
| 模型推論、檢索與服務工具 | 不隨包提供 | Skill 不授予能力或認證，不連線驗證 |

本包採一般純文字格式而降低對特定供應商的依賴。實際可用性仍需記錄 agent／模型版本、上下文限制、檔案讀取與公司權限邊界。

建議導入步驟：先做匯入檢核，再以虛構測資跑 13 題，保存實際輸出與審查紀錄；確認無外連與資料分級後，才由公司決定是否投入核准工作。這些是後續接收驗收，不是透過公司核准流程取得 main checkout 的先決條件。
