# 離線測試與驗收方式

本目錄提供 PM Skill 七題、架構 Skill 六題，共 13 題。所有情境都是完全虛構，不需要連線、登入、執行程式、付費或任何第三方模型額度。

## 接收者如何重跑

1. 使用公司已核准、可離線運作的 agent／模型。若環境尚未就緒，先由人員閱讀與審查，不改用外部服務。
2. 每題用全新 session，先只提供 [START-HERE.md](../START-HERE.md)、必要知識、選定的 SKILL.md 與該題指示需要的模板。
3. 再提供該題完整輸入。P-01／A-01 的工作輸入引用 examples 中的 input.md，須一併提供。
4. 作答時不要載入 [PRD 範例輸出](../examples/pm-prd/output.md)、[架構範例輸出](../examples/agent-architecture/output.md)、各題驗收答案、recorded 或 [驗證報告](../VALIDATION.md)，避免洩漏範例答案。
5. 保存實際輸出後，再由審查者讀 [PM 驗收](pm-prd/acceptance.md) 或 [架構驗收](agent-architecture/acceptance.md)，先過硬性門檻，再依品質量表評分。
6. 以 [評測紀錄模板](../templates/EVALUATION-LOG.tsv) 記錄版本、環境、輸入、輸出與證據。不要記錄認證值或真實敏感資料。

P-01／A-01 是完整文件題；其他題由測試輸入明確限制為針對性輸出，無須機械性重印整份模板。這些限制只縮小輸出，不授予任何動作權限。

## 本包已做與未做

recorded 是本次作者根據測試題撰寫的靜態回答與自評，不是第三方模型結果、盲測、獨立審查或公司 agent 實測。P-01／A-01 直接使用完整範例輸出，為品質樣本而非未見題。其餘回答也是可供審查的示範解法，不能據此推估某模型的通過率。

本次另以本地程式檢查 main checkout 中的交付文件結構、UTF-8、相對連結、雜湊、路徑與算式。驗證工具放在製作工作目錄，未放入可交付包；接收者沒有任何需要自動執行的程式。

導入時需補：實際模型／agent 的 13 題輸出、無外連與權限控制證據、公司的資料保存與審查決策。模型、Skill、工具、政策或工件版本改變後重新測試。
